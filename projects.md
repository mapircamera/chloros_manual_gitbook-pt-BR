# Interface gráfica: Projetos

O Chloros permite criar projetos que podem ser reabertos no futuro.

## Novo projeto

<figure><img src=".gitbook/assets/project_new.JPG" alt=""><figcaption></figcaption></figure>Selecione “Novo projeto” no menu principal e insira um nome exclusivo para o seu projeto.

## Abrir projeto

<figure><img src=".gitbook/assets/project_open.JPG" alt=""><figcaption></figcaption></figure>Selecione “Abrir projeto” para ver uma lista de projetos existentes na pasta de projetos. Se não houver projetos, o menu lateral secundário não será exibido. Você pode ver alguns projetos criados pela GUI (t1, t2, t3) listados na foto acima. Os projetos DATE\_TIME foram criados pelo CLI usando o esquema padrão de nomenclatura de projetos. Clicar em qualquer nome de projeto irá abri-lo.

Clicar no botão &quot;Abrir pasta do projeto&quot; abre o explorador de arquivos do seu computador no caminho do projeto. Você pode ajustar o caminho do projeto nas [Configurações do projeto](project-settings/project-settings.md).

## Adicionar arquivos

Depois que um projeto for aberto, selecione “Adicionar arquivos” no menu principal para adicionar arquivos de imagem individuais ao projeto atual. Isso espelha a funcionalidade de adição do navegador de arquivos, mas é acessível diretamente pelo menu principal para maior conveniência.

## Adicionar pasta

Depois que um projeto for aberto, selecione “Adicionar pasta” no menu principal para adicionar uma pasta inteira de imagens ao projeto atual. Arquivos duplicados são ignorados.

## Iniciar/Parar o processamento

Depois que os arquivos são adicionados a um projeto, a opção “Iniciar processamento” fica disponível no menu principal. Essa ação é equivalente a clicar no botão Reproduzir/Iniciar no cabeçalho superior. Durante o processamento, o item do menu muda para “Parar o processamento” para permitir que você interrompa o fluxo de trabalho.

{% hint style="info" %}
Os itens de menu “Adicionar arquivos”, “Adicionar pasta” e “Iniciar/Parar processamento” só ficam visíveis ou habilitados quando um projeto está aberto e os arquivos foram adicionados. Eles oferecem acesso rápido a ações também disponíveis na barra lateral do Navegador de arquivos e nos botões da barra superior.
{% endhint %}
